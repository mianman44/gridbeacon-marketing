# Homepage assets

The three `public/screenshots/gridbeacon-*.png` files are actual browser captures of the local GridBeacon app, captured on 2026-09-07. Only cropping was applied; no ranking values, branding, or report content was generated or changed.

- Heatmap: existing completed scan 1401, Infinity Garage Door - Austin Garage Door Repair, keyword `garage door installers near me`, September 2, 2026; 5 x 5 grid, 5-mile radius.
- Competitors: the same scan with the Competitors panel open.
- Report: the executive summary from report 15, version 9, associated with that scan.

The crops exclude account balances, account navigation, and profile controls. Map attribution remains in both map captures. These are historical examples, not live data or an endorsement by the listed businesses.

The hero at `public/artwork/local-advantage-city.webp` is decorative AI-generated architectural artwork, clearly captioned as a concept illustration. It is not a GridBeacon screen. Generated with the built-in image-generation tool and optimized to WebP.

Artwork brief: a monochrome orthographic architectural city model on pale mineral grey, leaving the upper left empty for the headline, with a translucent acid-lime coverage plane and three numbered rank markers; no interface, logos, headlines, charts, or dashboard panels.

Inter is self-hosted from the project's existing cached Latin variable font. Its license is included in `public/fonts/Inter-LICENSE.txt`.

The original homepage, header, footer, and layout are backed up at `../backups/marketing-before-premium-20260907/`.
